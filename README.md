# Beginner's Guide to Open Source

Welcome! This project is for people who are completely new to coding, GitHub and open-source development.

## What is this project?

A free, beginner-friendly learning guide to help people understand how to start coding and contribute to open-source projects.

## What you will learn

- What coding is
- What Git and GitHub are
- How to create your first repository
- How to write a README file
- How to find beginner-friendly open-source projects
- How to make your first contribution

## Learning roadmap

1. Learn basic computer skills
2. Start learning HTML and CSS
3. Understand Git and GitHub
4. Explore open-source projects
5. Make your first genuine contribution

## Who is this for?

Anyone who wants to learn coding from the beginning, especially people with no previous programming experience.
